How matching works

Ampon uses a rule based system: a fixed set of IF THEN rules written from shelter knowledge about pet care. There is no machine learning. The same answers always give the same result, and every recommendation lists the rules behind it.

1. Eligibility rules

Hard rules. If one fails, the pet is not recommended. For example, a pet that is not good with children is never recommended to a household with children.

2. Compatibility rules

Soft rules. Every eligible pet starts at 50 points, and each rule that applies adds or subtracts points. The final score from 0 to 100 ranks the results.

3. Readiness rules

Used by shelter staff. A rescued animal can only be listed for adoption after it passes every readiness rule.
